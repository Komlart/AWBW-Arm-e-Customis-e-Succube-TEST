# Crimson Libido · AWBW Texture Pack 💗

**Crimson Libido** est une armée personnalisée pour **Advance Wars By Web (AWBW)**. Elle comprend des sprites animés dessinés en pixel art, notamment des succubes et leurs animations de déplacement.

## Crédits

| Contribution | Crédit |
| --- | --- |
| **Sprites, pixel art et animations** de Crimson Libido | **Komlart** |
| Conception du projet et tests dans AWBW | **Komlart** |
| Développement et adaptation de l’importeur personnalisé, avec les correctifs 64×64 et gauche/droite | **ChatGPT (OpenAI)**, à la demande de Komlart |
| Script d’importation à l’origine du projet | **Vesper / ShinyDeagle**, auteur de *AWBW Custom Army Importer 2.7.1* |

La version personnalisée de l’importeur propose le bouton **💗 Lust Wars**, l’importation des armées depuis un dossier GitHub, l’affichage des unités GIF 64×64 dans un véritable cadre de 16×16 à l’écran et le retournement des animations de déplacement horizontal.

## Sources et installation

- Script original de Vesper : <https://greasyfork.org/en/scripts/521087-awbw-custom-army-importer-beta-2-7-1/code>
- Exemples de sprites et documentation de Vesper : <https://github.com/ShinyDeagle/My-Custom-Army>
- Version adaptée pour Crimson Libido : `Crimson-Libido-Importer-v1.1.user.js` (à installer dans Tampermonkey ou un gestionnaire de scripts compatible).

**Important :** il faut désactiver l’importeur de Vesper avant d’activer cette variante pour éviter que les deux scripts ne se gênent. Copier le lien du dossier de GIF dans un importeur non modifié ne charge pas automatiquement le script personnalisé.
